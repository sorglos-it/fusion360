# Utilisation

Retour à la [vue d'ensemble](index.md).

Le complément a une seule fonction : la commande **Élément SYSTEM 3E**. Elle place un élément de mur par exécution.

## Placer un élément

1. Ouvrir une conception dans Fusion.
2. Dans l'onglet **SOLID**, dans le panneau **Create**, cliquer sur **Élément SYSTEM 3E**.
3. **Point** : cliquer sur l'endroit prévu pour l'élément. Il est possible de cliquer sur
   - un point d'esquisse,
   - un coin d'un corps,
   - un point de construction – cela comprend les points d'un élément placé auparavant.

   Si l'on ne clique sur rien, l'élément va à l'origine de la conception. L'invite le dit :
   « Sélectionnez un point (aucun : origine) ».
4. **Famille** : choisir le groupe d'éléments.
5. **Élément** : choisir l'élément. Chaque entrée affiche le nom et la taille en mm sous la forme
   longueur x largeur x hauteur, par exemple `S1 WP   707 x 352 x 300`.
6. Regarder l'image sous la liste. Elle montre l'élément choisi.
7. **Poser par** : choisir quel endroit de l'élément arrive sur le point. Voir plus bas.
8. **Rotation** : saisir un angle si l'élément doit être tourné.
9. **Décalage X**, **Décalage Y**, **Décalage Z** : saisir une distance si l'élément doit être écarté du point.
10. Appuyer sur **OK**.

Il est aussi possible de cliquer d'abord sur le point, puis sur le bouton. Le complément reprend le point dans le
champ **Point**.

Tant que la boîte de dialogue est ouverte, Fusion montre l'élément à sa place en aperçu. Il est créé pour de bon
quand on appuie sur **OK**.

## L'image d'aperçu

- L'image montre l'élément choisi en vue ombrée grise, vu de l'avant gauche et d'en haut.
- Elle change quand on change **Famille** ou **Élément**.
- Les images sont dessinées à partir de la bibliothèque d'éléments. Elles ne sont pas reprises du catalogue du
  fabricant.

## Directions sur un élément

Ces mots sont utilisés pour les points et sous **Poser par**.

| Mot | Signification |
| --- | --- |
| avant | l'extrémité de l'élément à la longueur 0 |
| arrière | l'autre extrémité |
| droite, gauche | vu depuis l'extrémité avant, en regardant le long du mur |
| dessous | la face inférieure |
| dessus | la hauteur où repose le rang suivant (voir plus bas), ou le point le plus haut pour les deux coins supérieurs |

Un rang est une couche d'éléments dans un mur.

Avec **Rotation** 0, la longueur suit l'axe X de la conception, l'épaisseur du mur suit Y et la hauteur suit Z.
« Droite » est alors le côté où la valeur Y est la plus petite.

## Les douze points d'un élément

Chaque élément placé porte douze points de construction. Un point de construction est un point d'aide dans Fusion
sur lequel on peut cliquer. Les points ont des noms. Les noms sont écrits dans la langue que le complément
utilisait quand l'élément a été placé pour la première fois.

| Nom | Où il se trouve |
| --- | --- |
| dessous avant | face inférieure, extrémité avant, milieu de l'épaisseur du mur |
| dessous milieu | face inférieure, mi-longueur, milieu de l'épaisseur du mur |
| dessous arrière | face inférieure, extrémité arrière, milieu de l'épaisseur du mur |
| dessus avant | hauteur du rang suivant, extrémité avant, milieu de l'épaisseur du mur |
| dessus milieu | hauteur du rang suivant, mi-longueur, milieu de l'épaisseur du mur |
| dessus arrière | hauteur du rang suivant, extrémité arrière, milieu de l'épaisseur du mur |
| dessus milieu droite | hauteur du rang suivant, mi-longueur, face droite du mur |
| dessus milieu gauche | hauteur du rang suivant, mi-longueur, face gauche du mur |
| dessous milieu droite | face inférieure, mi-longueur, face droite du mur |
| dessous milieu gauche | face inférieure, mi-longueur, face gauche du mur |
| milieu droite, 50 mm plus haut | 50 mm au-dessus de la face inférieure, mi-longueur, face droite du mur |
| milieu gauche, 50 mm plus haut | 50 mm au-dessus de la face inférieure, mi-longueur, face gauche du mur |

« Hauteur du rang suivant » : les éléments qui ont le profil en relief sur le dessus portent le rang suivant 50 mm
sous leur point le plus haut. Les éléments plats le portent sur le dessus. Exemple : `S1 WP` a 300 mm de haut, le
rang suivant repose à 250 mm.

Le dessin montre tous les points sur l'élément de base `S1 WP`. Ses légendes sont en allemand. Jaune : peut être
cliqué. Rouge : peut être choisi sous **Poser par**. Vert : les deux.

![Les points sur l'élément S1 WP](../s1-wp-punkte.svg)

État : les points sont testés hors ligne seulement, **pas dans Fusion**.

## Poser par

**Poser par** décide quel endroit du nouvel élément arrive sur le point cliqué. La liste a 15 entrées :

| Entrée | Endroit de l'élément |
| --- | --- |
| Coin inférieur avant droit | coin le plus bas de l'extrémité avant, côté droit. C'est la valeur par défaut. |
| Coin supérieur avant droit | coin le plus haut de l'extrémité avant, côté droit |
| Coin supérieur avant gauche | coin le plus haut de l'extrémité avant, côté gauche |
| dessous avant … milieu gauche, 50 mm plus haut | l'un des douze points du tableau ci-dessus |

Les deux coins supérieurs utilisent la hauteur totale de l'élément, pas la hauteur du rang suivant.

État : les choix sous **Poser par** sont testés hors ligne seulement, **pas dans Fusion**.

## Rotation

- **Rotation** tourne l'élément autour de l'axe vertical. C'est l'axe Z de la conception.
- La rotation se fait autour de l'endroit choisi sous **Poser par**. Cet endroit reste sur le point cliqué.
- L'angle est donné en degrés. Un angle positif tourne dans le sens inverse des aiguilles d'une montre quand on
  regarde d'en haut.

## Décalages

- **Décalage X**, **Décalage Y** et **Décalage Z** écartent l'élément du point cliqué.
- Les valeurs sont en mm.
- Ils suivent les axes de la conception. Ils ne tournent pas avec l'élément.
- Les valeurs négatives déplacent dans l'autre sens.

Exemple : aucun point cliqué, **Décalage Z** 300 mm. L'élément est placé 300 mm au-dessus de l'origine.

État : les décalages sont testés hors ligne seulement, **pas dans Fusion**.

## Monter un mur à joints décalés

« À joints décalés » signifie : chaque rang est décalé d'un demi-élément par rapport au rang du dessous.

1. Placer le premier élément du rang le plus bas. Utiliser **Poser par** : **Coin inférieur avant droit**.
2. Relancer la commande. Choisir **Poser par** : **dessous avant**.
3. Cliquer sur le point **dessous arrière** de l'élément qui vient d'être placé. L'élément suivant prolonge le rang.
4. Répéter jusqu'à ce que le premier rang soit terminé.
5. Pour le deuxième rang, relancer la commande. Choisir **Poser par** : **dessous milieu**.
6. Cliquer sur le point **dessus avant** ou **dessus arrière** d'un élément du rang du dessous.
   Le nouvel élément repose alors pour moitié sur cet élément et pour moitié à côté.
7. Poursuivre le deuxième rang comme aux étapes 2 et 3.

Les réglages restent tels qu'on les a laissés ; il suffit donc de cliquer sur le point suivant et d'appuyer sur
**OK**.

Remarques :

- L'étape 6 est la méthode que la description du complément donne pour un mur à joints décalés. Les étapes 2 à 4
  découlent des positions des points ; elles ne sont **pas testées dans Fusion**.
- Sur les éléments qui ont une languette au bout (3 mm de plus, noms se terminant par `WP` ou `P`), les points
  **dessous avant** et **dessous arrière** se trouvent aux extrémités les plus extérieures. Vérifier le joint
  entre deux éléments dans la conception.
- Le complément ne vérifie pas si des éléments se chevauchent ni si un élément convient à un endroit.

## Liste de pièces : comment comptent les éléments identiques

- La première fois qu'un élément est placé, le complément crée un composant nommé `SYSTEM 3E <name>`,
  par exemple `SYSTEM 3E S1 WP`. Le corps qu'il contient porte le nom de l'élément, par exemple `S1 WP`.
- Chaque fois que le même élément est placé à nouveau dans cette conception, le complément ajoute une autre copie
  de ce même composant. Il ne crée pas de nouveau composant.
- Une liste de pièces affiche donc une seule ligne pour l'élément avec sa quantité, et non `S1 WP`, `S1 WP (1)`,
  `S1 WP (2)`.
- Le composant peut être renommé. Le complément le retrouve quand même, car il y laisse une marque invisible.
- Comme les copies partagent un seul composant, une modification du corps d'une copie modifie toutes les copies.
- Tous les éléments sont créés directement au niveau supérieur de la conception (le composant racine).
